    数据结构 → AI 优化映射详表¶

    本表是项目的核心导航。每行回答：「这个数据结构在哪个 AI 优化里被怎么用、为什么必须用它」。

    1. 数组 / 张量¶

    维度 内容
    数据结构 连续内存的元素序列，支持 O(1) 随机访问
    AI 优化 张量存储 + 分块矩阵乘法（Tiled MatMul）
    为什么必须 GPU/SIMD 要求内存连续才能并行；分块让矩阵乘法命中缓存
    不用会怎样 内存不连续 → 缓存未命中 → 性能下降 5~10 倍
    本章 demo 朴素矩阵乘法 vs 分块矩阵乘法的实测对比

    2. 链表¶

    维度 内容
    数据结构 节点 + 指针，O(1) 插入删除，O(n) 随机访问
    AI 优化 LRU 缓存 → KV Cache 淘汰策略
    为什么必须 LRU 需要「最近访问顺序」链表 + 哈希表，O(1) 淘汰
    不用会怎样 用数组维护顺序 → 淘汰 O(n)，长序列下不可接受
    本章 demo 哈希表 + 双向链表实现的 LRU，对比朴素 LRU

    3. 栈¶

    维度 内容
    数据结构 LIFO，O(1) 入栈出栈
    AI 优化 自动微分反向传播栈
    为什么必须 链式法则的求值顺序天然是反拓扑序，栈正好表达
    不用会怎样 用数组手动维护求值顺序 → 代码复杂且易错
    本章 demo 手写反向传播栈，对比 PyTorch autograd 结果

    4. 循环队列¶

    维度 内容
    数据结构 固定大小 + 头尾指针，O(1) 入队出队，空间复用
    AI 优化 Ring-AllReduce 分布式通信 + 批处理调度
    为什么必须 Ring-AllReduce 在环形拓扑上分片流动，带宽最优
    不用会怎样 树形通信 → 带宽利用率低，大模型训练慢
    本章 demo 模拟 Ring-AllReduce vs 树形 AllReduce 通信量对比

    5. 哈希表¶

    维度 内容
    数据结构 桶 + 哈希函数，平均 O(1) 查找
    AI 优化 词嵌入查找 + MoE 路由
    为什么必须 词表 10 万级，O(1) 查找才能让 embedding 层不拖后腿
    不用会怎样 用排序数组 + 二分 → O(log n)，长序列训练慢
    本章 demo 哈希 embedding 查找 vs 二分查找的性能对比

    6. 堆¶

    维度 内容
    数据结构 完全二叉树 + 堆序，O(log n) 插入，O(1) 取顶
    AI 优化 Top-K 采样 + Beam Search
    为什么必须 Top-K 只需维护 K 大小的小顶堆，O(n log k)
    不用会怎样 全排序 → O(n log n)，k << n 时浪费
    本章 demo 堆 Top-K vs 排序 Top-K，k=10, n=1e6 的对比

    7. Trie¶

    维度 内容
    数据结构 前缀树，公共前缀共享节点
    AI 优化 BPE 分词（最长前缀匹配）
    为什么必须 子词词表大，Trie 让最长匹配 O(词长)
    不用会怎样 每个候选子词独立查哈希 → 重复哈希 + 无法利用前缀
    本章 demo Trie BPE vs 朴素 BPE 分词速度对比

    8. KD-Tree¶

    维度 内容
    数据结构 k 维空间二分，按轴交替切分
    AI 优化 KNN 加速
    为什么必须 平均 O(log n) 近邻查询，朴素 O(n)
    不用会怎样 高维下退化为 O(n)，但低维仍有效
    本章 demo KD-Tree KNN vs 朴素 KNN，2D / 10D / 100D 对比

    9. 图¶

    维度 内容
    数据结构 顶点 + 边，邻接表 / 邻接矩阵
    AI 优化 PageRank + GNN 消息传递
    为什么必须 稀疏图用邻接表省内存，消息传递只遍历实际边
    不用会怎样 邻接矩阵存稀疏图 → O(V²) 内存爆炸
    本章 demo 邻接表 GNN 消息传递 vs 邻接矩阵版本

    10. 并查集¶

    维度 内容
    数据结构 父指针 + 路径压缩 + 按秩合并，近 O(1)
    AI 优化 层次聚类（HAC）的连通分量维护
    为什么必须 聚类合并频繁，并查集让合并近 O(1)
    不用会怎样 用 BFS/DFS 判连通 → 每次合并都 O(V+E)
    本章 demo 并查集聚类 vs BFS 聚类的合并次数对比

    11. 页表 / 分块内存（专题）¶

    维度 内容
    数据结构 页表 + 固定大小块 + 空闲块池
    AI 优化 PagedAttention（vLLM 的 KV Cache 管理）
    为什么必须 KV Cache 长度可变，连续分配会碎片化，分页消除碎片
    不用会怎样 连续分配 → 碎片化 → 显存利用率 30~60%；分页 → 95%+
    本章 demo 朴素 KV Cache 分配 vs PagedAttention 分配的显存利用率对比

    12. 跳表 + 图（专题）¶

    维度 内容
    数据结构 跳表（多层索引链表）+ 近邻图
    AI 优化 HNSW 向量检索
    为什么必须 跳表给图入口点快速定位，图给贪心搜索路径
    不用会怎样 纯图 → 入口点选择慢；纯跳表 → 高维退化为 O(n)
    本章 demo HNSW vs 暴力 KNN，1M 向量的检索延迟对比

    阅读建议¶

    • 想快速了解全貌：先读本表 + 各章 docs/ai_application.md 的「为什么必须」段
    • 想深入实现：按章节顺序读 docs/principle.md → c/ → docs/ai_application.md → python/
    • 想看性能数字：直接跑各章 python/demo.py，或看 benchmarks/ 汇总

    扩展篇：数据结构 × AI 应用工程（13-18 章）¶

    前 12 章聚焦「一个数据结构 → 一个 AI 系统优化」（性能视角）。 扩展篇聚焦「一个 AI 应用场景 → 多种数据结构协作」（架构视角）。 两种视角互补：前者讲单点性能，后者讲系统架构。

    13. 多智能体编排¶

    维度 内容
    AI 场景 多个 AI agent 协作完成复杂任务（如 LangGraph、AutoGen、CrewAI）
    涉及数据结构 图(DAG) + 队列 + 堆 + 并查集
    协作方式 agent 依赖关系→DAG 拓扑排序决定执行顺序；agent 间消息→队列；任务优先级→堆；agent 分组→并查集
    本章 demo 模拟多 agent 编排：DAG 调度 + 消息传递 + 优先级 + 分组

    14. 任务调度与批处理¶

    维度 内容
    AI 场景 LLM 推理服务的任务调度、动态批处理、负载均衡
    涉及数据结构 堆 + 图(DAG) + 队列 + 一致性哈希
    协作方式 优先级调度→堆；任务依赖→DAG 拓扑序；批处理队列→队列；多节点负载均衡→一致性哈希
    本章 demo 模拟推理服务调度：优先级 + 依赖 + 动态批处理 + 负载均衡

    15. 上下文工程与记忆¶

    维度 内容
    AI 场景 LLM 的 context window 管理、prompt 工程、短期/长期记忆
    涉及数据结构 LRU + Trie + 哈希 + 环形缓冲 + 栈
    协作方式 context 淘汰→LRU；prompt 前缀共享→Trie；记忆检索→哈希；对话滑动窗口→环形缓冲；调用嵌套→栈
    本章 demo 模拟 context 管理：淘汰 + 前缀共享 + 记忆检索 + 滑动窗口

    16. RAG 与知识检索¶

    维度 内容
    AI 场景 检索增强生成（RAG）：语义检索 + 关键词检索 + 知识图谱 + 去重
    涉及数据结构 HNSW + 倒排索引 + 图 + 布隆过滤器
    协作方式 语义检索→HNSW；关键词→倒排索引；知识图谱→图；结果去重→布隆过滤器
    本章 demo 模拟 RAG pipeline：多路检索 + 融合 + 去重

    17. 数据管道与流式处理¶

    维度 内容
    AI 场景 AI 训练数据的流式加载、滑动窗口统计、近似去重
    涉及数据结构 队列 + 环形缓冲 + 树状数组 + 布隆过滤器
    协作方式 数据管道→队列；流式数据→环形缓冲；滑动窗口统计→树状数组；近似去重→布隆过滤器
    本章 demo 模拟数据管道：流式加载 + 窗口统计 + 去重

    18. 模型部署与推理服务¶

    维度 内容
    AI 场景 模型部署的算子融合、请求调度、负载均衡、显存管理
    涉及数据结构 图 + 堆 + 一致性哈希 + 页表
    协作方式 算子融合→图优化；请求调度→堆/优先队列；负载均衡→一致性哈希；显存管理→页表/分块
    本章 demo 模拟推理服务：算子融合 + 请求调度 + 负载均衡 + 显存管理
    ## 19. 状态机与工作流
