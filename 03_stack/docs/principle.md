# 栈原理

> 本文档讲清「栈是什么、怎么实现、为什么 LIFO 有用」。AI 应用见 `ai_application.md`。

## 1. 栈的定义

栈是后进先出（LIFO, Last In First Out）的线性表：

```
入栈: push(1), push(2), push(3)
栈:  [1, 2, 3]  ← 顶
出栈: pop() → 3, pop() → 2, pop() → 1
```

两个核心操作：
- `push(v)`：压入栈顶，$O(1)$
- `pop()`：弹出栈顶，$O(1)$

**LIFO 是栈的本质**：最后放进去的最先出来。

## 2. 为什么 LIFO 有用

LIFO 自然匹配「需要回溯」的场景：

| 场景 | 为什么 LIFO |
|---|---|
| 函数调用栈 | 最后调用的函数最先返回 |
| 括号匹配 | 最后开的括号最先闭 |
| 表达式求值 | 最后压入的操作数最先参与运算 |
| DFS 深度优先搜索 | 最后访问的节点最先回溯 |
| **反向传播** | **最后计算的操作最先求导（链式法则的逆序）** |

## 3. 栈的实现：数组 vs 链表

### 3.1 数组栈（本章实现）

用动态数组，`size` 就是栈顶指针：

```c
bool ds_push(DStack *s, double v) {
    if (s->size == s->capacity && !ds_grow(s)) return false;
    s->data[s->size++] = v;  // 放在 size 位置，size+1
    return true;
}

bool ds_pop(DStack *s, double *out) {
    if (s->size == 0) return false;
    *out = s->data[--s->size];  // size-1，取出
    return true;
}
```

- push：写 `data[size]`，`size++`
- pop：`size--`，读 `data[size]`
- 无需移动元素，$O(1)$

### 3.2 链表栈

用链表头作为栈顶：

```c
void push(Node **top, int v) {
    Node *n = new_node(v);
    n->next = *top;
    *top = n;
}
```

- push：新节点插到链表头
- pop：删链表头

### 3.3 对比

| 维度 | 数组栈 | 链表栈 |
|---|---|---|
| 内存 | 连续，缓存友好 | 分散，缓存不友好 |
| 扩容 | 偶尔 $O(n)$ | 无需 |
| 空间 | 仅元素 | 元素 + 指针 |

**数组栈更常用**（缓存友好 + 空间紧凑）。函数调用栈就是数组栈（一块连续内存 + 栈顶指针）。

## 4. 复杂度

| 操作 | 复杂度 |
|---|---|
| push | $O(1)$ 摊还 |
| pop | $O(1)$ |
| peek | $O(1)$ |
| size | $O(1)$ |

## 5. C 实现要点

本项目的栈用动态数组（第 01 章）实现：
- `data`：double 数组
- `size`：当前元素数 = 栈顶位置
- `capacity`：容量，倍增扩容

扩容时用 `realloc`，摊还 $O(1)$。

## 6. 栈 vs 队列

| 维度 | 栈 (LIFO) | 队列 (FIFO) |
|---|---|---|
| 出序 | 后进先出 | 先进先出 |
| 适合 | 回溯、递归、反向传播 | BFS、调度、流水线 |
| 实现 | 数组（栈顶指针） | 数组（头尾指针）或链表 |

栈用于「回溯」，队列用于「公平调度」。反向传播是回溯（第 03 章），批处理调度是公平（第 04 章）。

## 7. 小结

栈的核心：
1. **LIFO** → 后进先出，匹配回溯场景
2. **数组实现** → $O(1)$ push/pop + 缓存友好
3. **反向传播** → 链式法则的逆序天然用栈
