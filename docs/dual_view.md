# 双视角说明

> 本项目用**两个视角**讲「数据结构 × AI」，同一批数据结构从两个角度切入，互补但不依赖。

## 视角 A：数据结构 → AI 系统优化（前 12 章）

**组织维度**：按数据结构分章（数组→链表→栈→队列→...）

**每章逻辑**：一个数据结构 → 它在某个 AI 系统优化里怎么用 → 性能提升多少

**聚焦**：单点性能。回答「这个数据结构为什么必须用？不用会怎样？」

**例子**：
- 第 11 章：页表 → PagedAttention → 显存利用率 23%→85%
- 第 12 章：跳表+图 → HNSW → 检索快 10x

## 视角 B：AI 应用场景 → 多种数据结构协作（扩展篇 13-20 章）

**组织维度**：按 AI 应用场景分章（多智能体→任务调度→上下文工程→...）

**每章逻辑**：一个 AI 应用场景 → 多种数据结构如何协作解决它 → 协作的效果

**聚焦**：系统架构。回答「这个 AI 应用需要哪些数据结构协作？为什么是这些？」

**例子**：
- 第 13 章：多智能体编排 → DAG+队列+堆+并查集协作 → 优先级调度 23.5x
- 第 16 章：RAG → HNSW+倒排索引+图+布隆过滤器协作 → 召回率 62%→100%

## 两个视角的关系

```
视角 A（数据结构 → 优化）        视角 B（应用 → 协作）
┌─────────────────────┐        ┌─────────────────────┐
│ 数组 → 分块矩阵乘法   │        │ 多智能体编排          │
│ 链表 → LRU KV Cache  │        │  ├─ DAG 拓扑排序     │ ← 第09章的图
│ 栈 → 反向传播         │        │  ├─ 队列消息传递     │ ← 第04章的队列
│ 队列 → Ring-AllReduce │        │  ├─ 堆优先级调度     │ ← 第06章的堆
│ ...                  │        │  └─ 并查集分组       │ ← 第10章的并查集
│ 页表 → PagedAttention │        │                      │
│ 跳表+图 → HNSW        │        │ RAG 检索             │
└─────────────────────┘        │  ├─ HNSW 语义检索    │ ← 第12章的跳表+图
        │                      │  ├─ 倒排索引关键词   │
        │                      │  ├─ 图知识图谱       │ ← 第09章的图
        │                      │  └─ 布隆过滤器去重   │
        │                      └─────────────────────┘
        │                              │
        └──────────  同一批数据结构 ─────┘
```

**关键**：两个视角讲的是**同一批数据结构**，但切入点不同：
- 视角 A 从「数据结构」切入，讲它在 AI 里的单点价值
- 视角 B 从「AI 应用」切入，讲它需要哪些数据结构协作

**不是层级关系**：视角 B 不是视角 A 的进阶，两者可独立阅读。
**互补关系**：视角 A 让你理解每个数据结构的原理和价值，视角 B 让你看到它们如何协作解决真实 AI 问题。

## 阅读建议

- **先学数据结构**：按视角 A 顺序读（01→12），建立每个数据结构的基础
- **再看 AI 应用**：按视角 B 选读感兴趣的专题（13-20），看数据结构如何协作
- **交叉对照**：读视角 B 时遇到不熟悉的数据结构，回视角 A 对应章节补课
